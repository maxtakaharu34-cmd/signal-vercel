## 発見 → 取り入れたこと

| 観点 | 確認した問題 | 実装した改善 |
|---|---|---|
| シグナルの説明 | 方向と6段階だけでは変化の理由を追えない | 判定足の時刻、直近20判定、開閉式の算出内訳 |
| 期間の比較 | 短期と中期で違う動きを区別できない | 8・24・60本の騰落率と方向、一致/不一致 |
| 価格とシグナルの整合性 | 管理者指示・揺れを含む表示と、価格指標を混同しやすい | 価格だけの参考情報とシナリオのシグナルを明確に説明 |
| 指標の計算 | RSI/ATRは単純な直近平均だった | 14本のWilder平滑へ変更。連続反転後の値とATRの減衰を検証 |
| チャート操作 | 新しい足が届くと検査中の足が解除された | 足の生成番号で選択を保持、縦横クロスヘア、最新足ボタン、Escapeで解除 |
| 時刻 | 軸が生成番号だけだった | 自動生成アンカーから実際のJSTを表示。時刻が不明な古い足は番号のまま |
| スマホ | 追加情報で横幅が溢れる可能性 | 下部「分析」に3期間を横並び、補足情報は縦並び。6サイズで実測 |
| 更新負荷 | マウス移動でも分析を計算し直す | 同じ受信データでは分析を再計算せず、描画対象の履歴も最大20判定に制限 |
| 共有と履歴 | 閲覧者ごとにランダムな履歴を作ると食い違う | 共通アンカー・シード・サーバー時刻から復元。履歴の重なる部分が次回取得後も一致することを検証 |
| 権限・通信 | 外観変更で管理権限や保存を壊すリスク | 既存の所有者確認、競合検知、オフライン表示、再同期のテストを維持 |

## 数値の意味

- 8/24/60は生成本数。市場の8分/24分/60分という意味ではない。方向の中立帯はATRと期間を用いた独自の参考ルール。
- 変動比較は直近8本のTrue Range平均 / その前24本の平均。1.3倍超を拡大、0.7倍未満を縮小とする独自ルール。
- シグナルの内訳は、実際に合成・平滑化に使っている方向指示、仮想価格の勢い、シナリオの揺れ、移行前の状態。勝率や将来の確率を示さない。
- 直近20判定は現在の自動シナリオの計算履歴であり、管理操作ログとは別。停止・手動設定時に架空の自動履歴を追加しない。
- RSI/ATR/EMAの計算は取得済みの最大120本を使用。市場の全履歴を使った指標との一致を保証しない。
